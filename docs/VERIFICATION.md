## 磁盘分析

`DiskNetworkSmoke` 使用临时文件夹验证了以下场景：

- 文件逻辑大小汇总、一级目录分布及根目录文件分组一致。
- 空文件夹保留，最大文件列表最多 100 项，扫描不改变源文件。
- 扫描开始前取消、扫描过程中取消、无效路径处理。
- Windows 访问权限拒绝时跳过目录，并明确记录跳过项和错误；测试后恢复临时目录权限。

符号链接循环测试因当前 Windows 会话没有创建符号链接权限而跳过，未将其计为通过。扫描代码会跳过文件和目录的所有重解析点。

## 发布版本参数

`build.ps1` 和 `publish.ps1` 的 PowerShell 语法检查通过。版本参数会拒绝两段版本、带 `v` 前缀、预发布后缀、前导零、超过程序集范围的数值及夹带命令字符的输入。

发布工作流通过环境变量读取标签，再将去除 `v` 的三段版本作为参数传入。应用和烟雾测试使用相同的版本属性构建；打包前还会核对发布 DLL 的程序集版本。实际 GitHub Actions 和 GitHub Release 发布需在仓库连接后执行。

## 硬件数据的适用范围

传感器支持程度依赖硬件、驱动及 Windows 权限，无法获取的数据应显示为不可用。CPU 的零温度不能作为有效温度；GPU 驱动是否支持遥测也不能据此推断硬件健康。上述磁盘扫描验证针对空间分析，不等同于文件系统修复或硬盘坏道检测。
