Roger v0.3.0 增加异常提醒、进程资源排行、七天历史监控和持久化优化记录，并提供 Windows 安装器。

## 下载与安装

- **推荐：`Roger-Setup-0.3.0-x64.exe`** — Windows 10 / 11 x64 安装器，创建快捷方式和卸载入口；自包含 .NET，检测并自动安装缺失的官方签名 PawnIO 2.2.0 温度驱动，支持离线安装依赖。
- **便携版：`Roger-win-x64.zip`** — 解压完整目录后运行 `Roger.exe`；无需另装 .NET。缺少 PawnIO 时可在硬件页面安装官方驱动。
- **校验：`SHA256SUMS.txt`** — 安装器与便携包的 SHA-256。

程序默认请求管理员权限。依赖安装失败会明确提示，若驱动需要重启则显示重启提示，不自动重启。Roger 安装器与程序目前未进行商业代码签名，Windows 可能显示未知发布者；随安装器提供的 PawnIO 是经过校验的官方签名版本。

## 新增与改进

- **异常提醒**：每个可读 CPU / GPU 独立温度判断，内存紧张、各卷空间不足提醒；可配置阈值、持续时间、冷却及静音，本地保留最近 500 条记录。
- **进程排行**：CPU、内存工作集、进程 I/O 读取和写入排序，名称 / PID 搜索，显示前 100 项及可读路径；不会结束或重新配置进程。
- **历史监控**：本地保存七天分钟汇总，一小时 / 一天 / 七天视图、平均与采样峰值、CSV 导出；显卡分别统计，关闭软件的时段不补造数据。
- **优化记录与恢复**：电源、客户端动画修改前保存原值，跨重启查看和恢复；恢复前核对当前值，冲突时不覆盖；DNS 刷新保留不可撤销的执行结果。
- **硬盘硬件**：物理设备型号、总线、SSD / HDD、卷映射、活动率、读写速度、队列、响应时间和设备提供的温度、磨损、Windows 状态。
- **多品牌适配**：Intel / AMD CPU，NVIDIA / AMD / Intel GPU，支持概览与监控条显卡选择，区分专用及共享 GPU 内存，显示内存条固件信息。
- **界面与启动**：主题一致的托盘右键菜单、列表选择和滚动；默认管理员启动；已经开启的登录自启会跟随当前程序位置更新。

升级和卸载保留 `%LOCALAPPDATA%\Roger` 中的配置、提醒、历史与优化记录；卸载清理当前用户的 Roger 自启入口，保留共享 PawnIO 驱动。

## 验证与范围

Release 构建与完整离线冒烟检查通过，包括持续阈值、PID 重用、历史保存重载、损坏文件保留、恢复冲突和文件系统检查。优化写操作通过模拟接口验证，测试未修改开发机器的电源、动画或 DNS 设置。亮暗主题、最小窗口尺寸、导航和按钮可达性均已检查。

温度、寿命与部分硬件字段仍取决于具体型号、固件及驱动；缺失字段显示不可用。Windows 磁盘状态不代表完整 SMART 检查。内存为工作集，进程 I/O 可包含网络及设备操作，不等同于物理磁盘吞吐。
