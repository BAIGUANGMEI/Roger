Roger v0.4.0 新增软件内更新，修复任务栏监控条单击闪烁与重复置顶。

## 下载与安装

- **推荐：`Roger-Setup-0.4.0-x64.exe`** — Windows 10 / 11 x64 安装器，创建快捷方式和卸载入口；自包含 .NET，自动检测并安装缺失的官方签名 PawnIO 2.2.0 温度驱动，依赖可离线安装。
- **便携版：`Roger-win-x64.zip`** — 解压完整目录后运行 `Roger.exe`，无需另装 .NET；缺少 PawnIO 时可在硬件页面安装。
- **校验：`SHA256SUMS.txt`** — 安装器与便携包的 SHA-256。

两种完整发布包都包含独立更新组件 `Roger.Updater.exe`。程序默认请求管理员权限；已有兼容 PawnIO 驱动时跳过安装，需要重启 Windows 时提示用户手动重启，不自动重启电脑。

**从旧版升级：** 公开的 v0.3.0 及更早版本没有独立更新组件，请先下载安装 v0.4.0，或替换为完整的 v0.4.0 便携目录。手动安装前从托盘菜单退出 Roger。此后可直接在软件内更新到更高版本。

## 新增与修复

- **软件内更新**：在“版本与更新”页检查 GitHub 正式 Release，点击“下载并更新”即可下载、校验 SHA-256、保存历史并正常退出，由独立组件更新后重新打开 Roger。安装版沿用当前目录；便携版备份被替换文件，替换失败时尝试恢复。
- **更新进度与结果**：显示下载字节数与进度，下载期间可取消，失败后可重试；重新进入版本页可查看上次结果和更新日志。启动时检查只查询版本，不自动安装。
- **监控条单击闪烁**：单击不激活监控条；超过系统拖动阈值才开始移动，松开后保存位置。保留双击打开主窗口和右键菜单。
- **任务栏层级恢复**：任务栏遮挡恢复请求合并处理；仅在实际被遮住或丢失置顶标记时调整层级，稳定显示时不反复置顶。

升级保留 `%LOCALAPPDATA%\Roger` 中的配置、提醒、历史和优化记录。安装器不强制结束 Roger，更新组件等待应用正常退出后才替换文件。

## 验证与边界

完整冒烟检查和桌面监控条回归通过，包括下载校验、取消重试、退出交接、安装结果及目标版本核验、便携路径检查与回滚。安装和系统修改通过模拟接口验证，未为测试运行真实更新安装器或修改本机优化设置。亮暗主题、两种窗口尺寸及四种更新状态的十六组离屏布局检查通过；实际 GitHub 下载测试核对了公开 v0.3.0 安装器及 SHA-256，未执行该安装器。更多记录见 [验证说明](https://github.com/BAIGUANGMEI/Roger/blob/v0.4.0/docs/VERIFICATION.md)。

安装器失败不保证完整回滚；便携恢复失败时报告保留的备份位置。硬件温度等读数仍取决于设备、固件、驱动和权限。

Roger 程序、更新组件和安装器目前未进行商业代码签名，Windows SmartScreen 仍可能显示未知发布者。SHA-256 用于验证下载完整性，不代替代码签名；随安装器提供的 PawnIO 是核验过的官方签名原包。
