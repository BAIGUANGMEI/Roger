# Interface icons

These SVGs were downloaded from the official [Lucide repository](https://github.com/lucide-icons/lucide).
`UPSTREAM.txt` records the exact source commit. The originals are retained unchanged.

`Icons.xaml` contains WPF path geometries generated by `scripts/generate_icon_resources.py`.
The shapes retain the original 24 × 24 viewport; render inside a 24 × 24 `Canvas` in a `Viewbox`,
with no fill, a 2-unit stroke, and round stroke caps and joins. The stroke uses Roger's active theme.
Caption controls use the same downloaded icon family: minus, square, copy, and x.

The ISC and inherited Feather MIT license notices are in [`third_party/Lucide/LICENSE`](../../../../third_party/Lucide/LICENSE).
